
# Bulk Index Checker - مهارة لـ Open Code / Claude Code

## التركيب في Claude Code:
1. انسخ الفولدر ده إلى:
   Windows: %USERPROFILE%\.claude\skills\bulk-index-checker
   Mac/Linux: ~/.claude/skills/bulk-index-checker

2. افتح Claude Code واكتب:
   /bulk-index-checker افحص الأرشفة

## التركيب في OpenCode (opencode.dev):
1. انسخ الفولدر إلى:
   .opencode/skills/bulk-index-checker في مشروعك
   أو ~/.config/opencode/skills/bulk-index-checker عام

2. في OpenCode اكتب:
   افحص لي مشاكل الأرشفة في healthfingerprint.com

## الاستخدام المباشر:
   python scripts/check_indexing_bulk.py
